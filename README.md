# Java Lab

## English
A collection of the code I write while learning Java: basics, arrays, strings and small console projects.

## Türkçe
Java öğrenirken yazdığım kodların toplandığı repo: temeller, diziler, string'ler ve küçük konsol projeleri.

---

## Folder Structure / Klasör Yapısı

All code is in `src/`. / Tüm kodlar `src/` içindedir.

| Folder | Content / İçerik |
|--------|------------------|
| `hello_world/` | First Java program / İlk Java programı |
| `diziler/` | Arrays / Diziler |
| `strings/` | String operations / String işlemleri |
| `kitle_endeksi/` | Body mass index calculator / Vücut kitle endeksi hesaplama |
| `yerDegistir/` | Swapping values / Değer yer değiştirme |
| `miniProjeler/` | Small projects: prime numbers, perfect numbers, grade average, number guessing, vowels / Küçük projeler: asal sayı bulma, mükemmel sayı, not ortalaması, sayı bulma, sesli harfler |

## How to Run / Nasıl Çalıştırılır

1. Clone the repo / Repoyu klonla:
   ```bash
   git clone https://github.com/taha-yasind/java-lab.git
   ```
2. Open it in IntelliJ IDEA / IntelliJ IDEA ile aç
3. Run the `main` method of any file / İstediğin dosyanın `main` metodunu çalıştır
